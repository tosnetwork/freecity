# FreeCity

**The accountability surface for the autonomous Agent economy.** It renders
finalized on-chain facts as a living city a human can read at a glance, and
every pixel traces back to the transaction that produced it.

FreeCity owns no economic authority. Identity, capability, quotes, escrow,
receipts, and settlement live in TOS Service, whose sole authority is finalized
TOS chain state. FreeCity is a replaceable projection over that, plus the human
comprehension layer on top.

- [`POSITIONING.md`](POSITIONING.md) — what FreeCity is, why, its invariants,
  and the one bet it can lose
- [`ROADMAP.md`](ROADMAP.md) — milestones, each retiring a named risk behind a
  gate that can fail
